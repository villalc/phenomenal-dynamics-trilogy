# Matriz de Alineacion · Shadow Copy vs Repo Privado

## Se queda en esta copia Shadow
- Experimentacion de umbrales y politicas no estabilizadas.
- Mapeos agresivos de metricas fenomenales a decision Shadow.
- Ensayos de promotion gates y sesgos de exploracion.

## Migra al repo privado cuando cierre fase
- Esquema de manifiesto estable (ShadowRunManifest).
- Ledger de decisiones con hash chain verificable.
- Reportes ejecutivos reproducibles para gobernanza.

## No migra (solo referencia)
- Claims de ZK como garantia productiva (actualmente mock).
- Demos de UI conversacional sin control de evidencia.
- Scripts ad-hoc no versionados de experimentacion.

## Regla de paso de fase
Un componente migra si cumple las 4 condiciones:
1. Tiene esquema versionado.
2. Tiene prueba minima automatizada.
3. Produce artefacto reproducible.
4. No rompe frontera governance/experimental.
